# App-finance-Claude

Application personnelle de pilotage financier (fichier unique `index.html`, données stockées dans le navigateur).

À la première ouverture, un **parcours d’accueil guidé** présente l’application puis aide à renseigner, étape par étape : le patrimoine, les coûts et dépenses (capacité d’épargne), les objectifs, puis la stratégie d’achat mensuelle.

Après le questionnaire, l’appli tient en 5 onglets : Accueil, Mon argent, Mes coûts, Mes projets, Mon plan.

Tests : `node tests/appli.e2e.js`. Voir `CHANGELOG.md` pour le détail des modifications, les tests et les limites. Version d’origine : `original/test_3010.html`.
